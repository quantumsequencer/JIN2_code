# 展示用 JIN SAMURAI

`test2` の現在のコードを複製した展示用アプリです。操作手順、通信、工程制御、停止・異常処理は引き継いでいます。`test2` への依存はなく、メーカーGatewayは兄弟フォルダの `SGMO2_original` を使用します。

## 起動

このフォルダで初回に実行します。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

- `StartUI.bat`：実機接続用。起動だけでは接続しません。
- `StartDemo.bat`：装置に接続しないシミュレーション。

## 表示

- 落ち着いたブルーグレーを基調に、淡い青の丸いカード・パステル色の工程バッジ・SAMURAIの吹き出しを使用します。キャラクター画像は静止し、用意したバリエーションだけを切り替えます。グラフの背景も淡い青で、波形は濃い色で表示します。

- 電流は元波形（グレー）と一次ローパス後の波形（水色）を同じグラフに重ねて表示します。カットオフは初期値100 Hz、0.1～5000 Hzで変更できます。低いほど滑らかになり応答が遅くなります。
- フィルタは表示区間の先頭値を初期値として再計算します。欠落・不連続・無効値で区切り、元のサンプルを変更しません。制御判定・解析・保存値や数値メーターは従来どおりです。
- モーター（緑・左軸 µm）とピエゾ（紫・右軸 nm）は共通の時間軸で表示し、縦軸はそれぞれ自動調整します。
- 詳細ログ・波形統計は初期状態で非表示です。「詳細ログ・波形統計を表示」で戻せます。中央値の補助線は非表示です。
- 数値メーター・電流波形・位置グラフを画面の中心に配置しています。
- 左側は大きなSAMURAIと進行状況です。11工程は2段の小さな一覧にし、現在の工程・完了した工程を色で示します。正式名称と説明はマウスを重ねると表示します。
- SAMURAIは6種類のジェスチャー×3バリエーション、計18枚の画像で案内します。画像は揺らしたり回転させず、約8秒ごと・工程の切り替わりに、その状況に合う候補からランダムに選びます。同じ画像は連続表示しません。短いセリフも工程に合わせて変化します。11工程の準備完了時だけ短い達成演出を表示し、異常・停止処理・実行中の受信待ちでは注意画像だけを使います。演出は工程や装置を操作しません。
- 基本操作（接続・設定適用・準備・レシピ作成／実行・停止）は画面下に常時表示します。準備全体・工程内・計測・レシピの進捗と終了見込みも残しています。チップ装着の確認は必要な工程で表示します。
- 「設定・詳細操作」から設定ファイル、通信設定、個別工程、ローパス調整、グラフ調整・判定表示などを開けます。操作の動作や自動進行の条件は従来どおりです。

設定は `setting parameter/setting_parameter.txt` の複製を使用します。開発用の過去データ・レポート・レシピ履歴はコピーしていません。展示用UIのレポート・レシピはこのフォルダ内に保存します。Gateway側の設定・生データ保存先は既存Gatewayと共通です。
